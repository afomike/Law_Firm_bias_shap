How to read this interaction plot

Y-Axis

Feature interaction pairs — Ethnicity×Ethnicity, Ethnicity×Gender, Gender×Gender — showing all pairwise interaction effects computed by SHAP.

X-Axis

SHAP interaction value magnitude. Larger absolute values mean stronger influence on the prediction output.

Dot Spread

Wide spreads indicate high variance in how a feature pair affects predictions — suggesting inconsistent or unstable model behaviour across this attribute combination.

Clustering

Tight clusters near zero mean the interaction has little effect. Clusters far from zero reveal systematic bias toward or against specific feature combinations.

What is SHAP?

SHAP (SHapley Additive exPlanations) is grounded in cooperative game theory. It assigns each feature a contribution value for each prediction, calculated so that contributions sum to the difference between the model output and a baseline. Interaction SHAP values extend this to pairs of features — revealing not just what matters, but how features work together to influence decisions. This makes it one of the gold standards for explainable AI in high-stakes hiring and lending applications.
